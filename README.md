# temperature-controlled-fan
My third Arduino electronics project, built using Tinkercad Circuits.

## What I built

A temperature-controlled fan using:

- Arduino Uno
- Temperature sensor (TMP36)
- DC motor

The fan automatically turns on when the temperature exceeds a set threshold and turns off when the temperature drops.

## What I learned

- Temperature sensors
- Reading analog inputs
- Conditional statements
- Controlling a DC motor
- Basic Arduino programming
- Using Tinkercad to simulate electronics
